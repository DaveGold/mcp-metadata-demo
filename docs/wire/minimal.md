## `get_weather_context`

### Description (87 chars)

````text
Look up daily weather and degree-day/solar metrics for a Dutch location and date range.
````

### Input parameters (delivered)

| parameter | type | description |
|---|---|---|
| `latitude` | number | Latitude in decimal degrees. Netherlands range: 50.75–53.55. Default: 52.09 (Utrecht). Get from get_building_profile coordinaten.lat, or use the regional default. |
| `longitude` | number | Longitude in decimal degrees. Netherlands range: 3.36–7.23. Default: 5.11 (Utrecht). Reference points: Amsterdam 52.37/4.90, Rotterdam 51.92/4.48, Den Haag 52.07/4.30, Utrecht 52.09/5.11, Eindhoven 51.44/5.48, Groningen 53.22/6.57. |
| `dateFrom` * | string | Start date in yyyy-MM-dd format. Historical data available from 1940-01-01. Europe/Amsterdam timezone. For annual normalization: use YYYY-01-01. |
| `dateTo` * | string | End date in yyyy-MM-dd format (inclusive). Max range: 730 days from dateFrom. May be today or up to 14 days in the future: recent/upcoming dates are served by the forecast API (flagged isForecast=true), which also bridges the archive’s ~2 day lag so measured days stay complete. Dates beyond today+14 are rejected. For annual normalization: use YYYY-12-31. |
| `summaryOnly` | boolean | If true, returns only aggregated summary without daily records. Recommended true for periods >30 days when only gasNormalizationFactor or degree-day totals are needed. |
| `select` | array | Return only these fields per daily record — a token saver for a long range where you need per-day detail (e.g. a full-year calendar or chart), not just the summary. Fields: date, tempMean, tempMin, tempMax, hdd, cdd, weightedHdd, ghiKwhM2, sunshineDurationHours, weatherCode, weatherLabel, isForecast. Ignored when summaryOnly=true (no records returned either way). |
| `queryIntent` | string | Describe what this weather data is being used for. Used for observability. |
