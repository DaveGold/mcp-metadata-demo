// get_weather_context: INTERPRETATION block of the tool description
INTERPRETATION:
- isForecast per day = MEASURED (archive) vs FORECAST (predicted). Forecast days are fine for a planning outlook (icon + temperature) but are excluded from degree-days, gasNormalizationFactor and solar totals — those summary aggregates cover the measuredDays only. Never normalize energy against a forecast day. This rule concerns `isForecast`, `measuredDays`, `forecastDays`, `totalHDD`, `totalWeightedHDD`, `totalCDD`, `gasNormalizationFactor`, `solarRadiation`. History: Written with the tool on 2026-08-29 (#20). The reason for this wording was not recorded.
- weatherCode is the raw WMO code; prefer weatherLabel (Dutch, "Onbekend" if the code is missing) for display. This rule concerns `weatherCode`, `weatherLabel`. History: Written with the tool on 2026-08-29 (#20). The reason for this wording was not recorded.
- gasNormalizationFactor = 2800 / totalWeightedHDD. The Dutch long-term average year has ~2800 weighted HDD. A cold year (factor < 1.0) means raw energy use looks high — but that's expected. A warm year (factor > 1.0) means raw energy use looks low. Formula: normalizedHeatingEnergy = actualHeatingEnergy × gasNormalizationFactor. IMPORTANT: gasNormalizationFactor is only valid for full-year (Jan 1–Dec 31) queries. For partial-period year-over-year comparison, use the HDD ratio directly: normalizedEnergy = energy × (refPeriodHDD / thisPeriodHDD). This rule concerns `gasNormalizationFactor`, `totalWeightedHDD`, `referenceAnnualHDD`. History: Written with the tool on 2026-08-29 (#20). The reason for this wording was not recorded.
- GHI (global horizontal irradiance) in kWh/m² = Peak Sun Hours (PSH) for the period. Expected solar yield = totalGHI_kWhM2 × installedKwp × performanceRatio (0.75–0.85 for healthy panels). If actual production < 70% of expected yield → investigate: inverter issue, soiling, shading, curtailment. This rule concerns `solarRadiation`. History: Written with the tool on 2026-08-29 (#20). The reason for this wording was not recorded.
- Dutch weighted HDD seasonal factors: Nov–Feb ×1.1, Mar/Oct ×1.0, Apr–Sep ×0.8. These account for solar gain: in summer, the sun provides heat gain that partially offsets heating demand. This rule concerns `weightedHdd`, `weightedHDD`, `totalWeightedHDD`. History: Written with the tool on 2026-08-29 (#20). The reason for this wording was not recorded.
- select: when requested, records are projected to only the named fields. Unknown field names are ignored (with an alert naming them, valid fields listed). If none of the requested fields are valid, zero records are returned — select never silently falls back to full records. This rule concerns `records`, `recordCount`. History: Written with the tool on 2026-08-29 (#20). The reason for this wording was not recorded.
