## How the three fit together

| talk | question | answer |
|---|---|---|
| _Most MCP servers are empty_ | where did the meaning go when the application disappeared behind the agent? | into the capability boundary |
| _Domain knowledge belongs in the MCP server_ | what context does a capability need, where does it live, and does the model receive and use it? | measure it: own the knowledge at the capability, deliver it where the model reads |
| _Adoption is the hard part_ | how does useful AI get into a real organisation without a platform programme first? | one problem, one ambassador, one capability; let usage improve it, then spread through reuse and skills |

Meaning, then reliability, then adoption. The architecture that ties them together:
